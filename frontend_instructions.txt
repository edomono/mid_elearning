Frontend Instructions for "Update Submission" Modal Behavior:

To ensure the modal remains open after a submission update, the frontend (HTML and JavaScript) needs to be modified to handle the update process via an AJAX request.

**1. Modify the Submission Update Form (HTML):**
Locate the form responsible for updating the submission within your HTML template (e.g., `user/assignment-details.html` or a fragment like `assignment-edit-modal.html`).

**2. Implement AJAX Submission (JavaScript):**
You will need to add JavaScript code to intercept the form submission, send an AJAX request to the `/user/submission/{id}/update` endpoint, and handle the response.

**Example using jQuery (if available in your project):**

```javascript
$(document).ready(function() {
    // Assuming your update form has an ID like 'updateSubmissionForm'
    $('#updateSubmissionForm').on('submit', function(event) {
        event.preventDefault(); // Prevent default form submission

        var formData = new FormData(this); // Get form data, including files

        $.ajax({
            url: $(this).attr('action'), // The form's action URL
            type: $(this).attr('method'), // The form's method (POST)
            data: formData,
            processData: false, // Important for file uploads
            contentType: false, // Important for file uploads
            success: function(response) {
                // Handle success:
                // - Display a success message within the modal (e.g., in a div with id 'modalMessage')
                $('#modalMessage').text(response).css('color', 'green');
                // - You might want to update other parts of the modal with new submission details
                //   (e.g., the submission status, file name, note). This would require the backend
                //   to return more structured data (e.g., JSON) or for you to re-fetch data.
                // - The modal will remain open because there's no page reload.
            },
            error: function(xhr, status, error) {
                // Handle error:
                // - Display an error message within the modal
                $('#modalMessage').text(xhr.responseText || 'An error occurred.').css('color', 'red');
                // - The modal will remain open.
            }
        });
    });
});
```

**Key points for the frontend changes:**
*   **Prevent Default Submission:** Use `event.preventDefault()` to stop the browser from performing a full page reload.
*   **AJAX Request:** Send the form data asynchronously to the server.
*   **Handle Response:** Process the `ResponseEntity<String>` (or JSON) returned by the server. Display appropriate messages to the user within the modal.
*   **Keep Modal Open:** Since there's no page reload, the modal will naturally stay open. You might need to clear previous messages or update content as needed.

**If you are not using jQuery, you would use native JavaScript's `fetch` API or `XMLHttpRequest` to perform the AJAX request.**

This change on the backend (returning `ResponseEntity`) combined with the AJAX submission on the frontend will achieve the desired behavior of keeping the modal open after a submission update.
